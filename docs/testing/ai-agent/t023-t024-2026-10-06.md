## 未完成 / 已知缺口（阻塞 T023/T024 勾选）

- **没有真实库执行**：MySQL/PostgreSQL 真实连接的查询、取消、进度未验证（需用户授权连接 + 环境变量门控的 live smoke）。
- **参数化未实现**：`ParameterizedQueryRequest`/`SqlParameter` 与驱动 bind 未做，非空参数一律拒绝。
- **取消语义**：SQLite 连接器只在语句开始前检查一次 `should_cancel`；MySQL/SQLite 先 `fetch_all` 再截断，内存未真正有界；`WITH ... SELECT` 不会追加默认 LIMIT。
- **`db.execute` 无工具实现**：`standard_sql_tool_specs` 公布了 Write 工具但没有对应 `AiTool`，且审批（T020 执行侧）未接；不能在未接审批前暴露给模型。
- **授权/作用域**：AI SQL 已有专属 `QuerySessionId`，且对象描述拒绝跨 target 的 database/schema；owner/grant/scope/revision 仍由 T020/T021 的上层权限链负责，尚未做真实多 scope live 验收。
- **结果分页**：回执缺 `returned_rows/total_rows/result_ref`，不能支撑 T027 分页闭环。
- **`timeout_ms`**：schema 已暴露但执行链未强制；需在接入时补上或与设计确认。
