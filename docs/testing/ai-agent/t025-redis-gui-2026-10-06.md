# T025 ⑤ 真实窗口 Redis 端到端（Zhipu GLM + 真实 Redis，2026-10-06，macOS / podman）

## 环境与隔离

- 配置库：复制到 `/private/tmp/fluxdb-redis-gui` 后以 `FLUXDB_AI_TEST_ROOT` 启动（**用户原始配置库不改**）。
- 模型：`Zhipu GLM`；Redis：podman `docker-redis`（`127.0.0.1:6379`，连接 id=3）。
- 目标由 debug 钩子固定：`FLUXDB_DEBUG_AI_TARGET='{"connection_id":3,"redis_db":0}'`（生产构建不读）。
- 只写形如 `fluxdb:ai:smoke:*` 的测试键，结束删除；凭据走宿主解密路径，未外显。

## 实机步骤与结果（真实点击）

| 步骤 | 操作 | 结果 |
|---|---|---|
| ① 发指令 | 面板输入"用 redis.scan 扫描 `fluxdb:ai:smoke:*`，再用 redis.execute 写入 `fluxdb:ai:smoke:gui=hello`" → 真实点击**发送** | 模型先调 `redis.scan`：**succeeded**（当时 keys 为空） |
| ② 写工具 | 模型接着调 `redis.execute` | `ai_turns=waiting_approval`、`ai_tool_calls(redis.execute)=waiting_approval` **无回执**、审批 `pending`；UI 渲染审批卡（批准执行/拒绝 + plan_hash 提示） |
| ③ 批准 | 真实点击**批准执行** | 审批被消费；`redis.execute` **succeeded**，回包 `SET ... → OK`；Turn `completed` |
| ④ 后端核对 | `podman exec libredesk_redis redis-cli GET fluxdb:ai:smoke:gui` | **`hello`**（写入真实生效）；随后模型再次 `redis.scan` 已能看到该键 |
