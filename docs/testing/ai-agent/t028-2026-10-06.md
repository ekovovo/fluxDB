## 实施前场景

| 场景 | 必须核对 |
|---|---|
| 初次与再次打开 | 抽屉默认、上次实际会话、draft、真实有数据与无数据，不创建空历史 |
| 两种形式 | 面板内切换、各自宽度、60%/40%上限、窄窗口、关闭/重开及重启恢复 |
| 发送 | 真实控件输入/点击 → 用户消息事务提交 → live事件 →同一助手part → 最终保存；不用手动刷新 |
| 停止与隐藏 | 停止发出取消，part最终interrupted；关闭面板仅隐藏、不会停止或重放 |
| 历史与折叠 | 顺序和ID对应数据库，切会话不串、展开列表恢复；不吞加载错误 |
| 异常 | 缺Agent/模型、失败Load、重试、失败保留草稿；loading时禁用重复动作 |
| 视觉 | 与实际浏览器原型等尺寸/主题对比，浅/深、正常/窄、有数据、首次读取前压缩 |
