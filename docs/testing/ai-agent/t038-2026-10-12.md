## 一、交付内容

### 存储层（`crates/fluxdb-storage/src/parts/ai_platform/knowledge.rs`）

- 独立表 CRUD/CAS：`save`（对象级 CAS，冲突拒绝覆盖）、`load`、`confirm`、`retire`、
  `delete`；标题/类型非空、正文与 scope/source 为受校验 JSON 且限制 64 KiB。
- 状态机：`proposed`（模型提议，不是事实）→ `confirmed`（用户确认可用）→ `retired`
  （终态，不可回滚、不可再确认）。确认/退休只能由用户入口触发。
- 作用域：`scope_json` 的连接/数据库白名单参与检索过滤；`list_confirmed_scoped`
  在无匹配目标时不返回有作用域条目，避免跨库口径混用。
- 有界读取：`confirmed_excerpt` 按 UTF-8 字符边界截断并给出剩余字节与续读提示。

### 运行期装配（`crates/fluxdb-app/src/parts/ai_knowledge_skills.rs`）

- Turn 开始按**固定目标**筛选 confirmed 知识；条目上限 20、每条摘录上限 1 KiB。
- 只在 `builtin.knowledge` 插件启用时注入；关闭或空结果时本轮完全不带知识提示。
- Turn 快照只写 `knowledge_ids`（不落正文），正文由运行期工具实例按需读取。

### 工具与引用

- 新增只读工具 `knowledge.read`（`ai_reference_details.rs`）：按 `offset`/`max_bytes`
  分段读取本轮授权条目，命中非本轮 ID 直接拒绝，回执带 `untrusted`/`scope`。
  装配时校验仍为 `confirmed`，退休条目连目录都装配不出来。
- `@` 候选按当前上下文来源 tab 的连接/库过滤（`ai_references.rs`），摘要只给
  标题/类型/作用域/revision，不展开正文。

真实窗口提问「查一下当月订单的净收入」。核对 `ai_tool_calls` 原始行：

| 工具 | 参数（节选） | 状态 | 回执（节选） |
|---|---|---|---|
| `knowledge.read` | `t038-live-1` | succeeded | `净收入 = sum(net_amount)，排除退款单（status=refunded）与今日预扣` |
| `knowledge.read` | `t038-live-2` | succeeded | `仅计入 status=paid 的订单，过滤退款` |
| `db.query` | `SELECT status, SUM(net_amount) AS total FROM orders WHERE created_at >= '2026-10-01' AND created_at < '2026-11-01' GROUP BY status` | succeeded | `paid 350.5 / pending 150.0 / refunded 300.0` |

模型回复正文里逐字复述了两条 confirmed 知识的措辞，证明知识确实进入了真实模型的

## 四、本轮实机验收暴露并修复的相邻缺陷

真实会话里出现两次失败工具调用：

```
db.query  {"target":"conn:7/db:main","sql":"SELECT date('now') AS today"}
→ {"ok":false,"code":"not_read_only","message":"只读入口拒绝该语句（unknown_function）"}
```

根因：`crates/fluxdb-app/src/parts/ai_sql_policy.rs` 的纯函数白名单不含日期/时间函数，
`analyze_sql` 按「未知函数不猜安全」降级为需授权，只读入口 `db.query` 随即拒绝。
模型无法用它确认「今天/当月」边界，只能改用文本比较。

修复：白名单补入无副作用的日期/时间函数（`date`/`time`/`datetime`/`strftime`/
`julianday`/`unixepoch`/`timediff`/`date_format`/`from_unixtime`/`unix_timestamp`/
`to_char`/`to_date`/`to_timestamp`/`year`/`month`/`day`/`extract` 等），并新增回归用例
`ai_sql_policy_date_and_time_functions_are_read_only`（同时断言写语句仍被判需授权，
白名单变宽不放过 DML）。
