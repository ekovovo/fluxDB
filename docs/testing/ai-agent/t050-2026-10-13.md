# T050 保留/清理/安全导出与测试快照

本轮按用户指定顺序实现 1→4；报告安全导出已在 T040 交付，一致快照 helper（`sessions::session_snapshot`）
沿用既有实现（保持原连接/AES，证据不含密钥/密文），本轮不新增备份/导入产品 UI。

## 1. 归档/历史分页

- Storage：`SessionListCursor` / `SessionOverviewPage` / `count_sessions` /
  `list_session_overviews_page`，键集分页 `(updated_at_ms DESC, id ASC)`；同时间用 id 兜底保证
  无重复、无遗漏；多取一行判断 `has_more`。
- App：`ai_sessions_total` / `ai_sessions_cursor` / `ai_sessions_has_more` / `ai_sessions_loading_more`；
  `LoadMoreAiSessions` 按 id 去重追加。
- Desktop：会话历史头部「共 N · 已加载 M」+「加载更多」（loading/disabled，到底消失）；同步 dispatch。
- 测试：storage `session_overview_paging_is_stable_without_duplicates_or_gaps`、
  `session_overview_paging_filters_archived_and_counts_by_status`；app
  `load_more_pages_session_history_without_duplicates_or_gaps`；桌面
  `ai_sessions_load_more_pages_real_list_and_hides_when_done`（真实点击 + 真实 SQLite）。

## 2. 依赖清理

- `sessions::purge_archived_session`：仅**已归档**会话可删，非终态 Turn 拒绝；单事务按 FK 依赖顺序
  清理全部从属行；`last_session_id` 指向本会话时置空；返回受控文件相对路径（`SessionPurgePlan`）。
- App：`PurgeAiSession`（CAS 复核 revision）→ 删库 → 受控根内删 spill/产物文件（越界/非 uuid 拒绝）。
- Desktop：会话行仅归档态显示删除按钮 + 确认弹框（Esc/遮罩/取消不写库）。
- 测试：storage `purge_requires_archived_session_and_rejects_active_turn`、
  `purge_archived_session_removes_all_dependents_and_returns_file_facts`；app
  `purge_archived_session_deletes_facts_files_and_rejects_active`（真实落点文件 + 对照会话）。

## 3. spill/产物空间与清理

- Storage：`storage_usage`（登记落点条数/字节）、`failed_artifact_paths`、`clear_artifact_path`。
- App：`purge_failed_artifact_files`（failed 终态已登记快照，删文件后清落点）、
  `purge_orphan_controlled_files`（受控目录内未登记 `<uuid>.json` 直接子文件；`ready` 与非 uuid 保留）、
  `ai_storage_usage`；接入运行期准备路径（失败仅告警，不阻断任务）。
- 测试：app `storage_cleanup_purges_failed_artifacts_and_orphans_but_keeps_ready`。

## 4. staged 崩溃恢复对账

- Storage：`recover_on_startup` 收集 `StagedArtifactCandidate`；`reconcile_staged_artifact`
  （`staged→ready|failed`，CAS）、`clear_staged_artifact_path`、`staged_artifact_candidates`。
- App：`reconcile_staged_artifacts` 核对字节/指纹——吻合 `staged→ready`（幂等、不丢已完成文件）；
  缺失/不符先清落点再置 `failed`，不留悬挂引用。
- 测试：app `staged_artifact_reconcile_promotes_verified_and_fails_missing`。
