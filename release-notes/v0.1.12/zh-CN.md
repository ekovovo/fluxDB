## 新功能

- 筛选条件支持表单与 SQL 输入双向切换：表单内容可自动带入输入框，输入的条件也能解析回可编辑表单，并保留 AND / OR、括号分组和排序规则。
- 条件输入支持搜索条件补全与 SQL 预览高亮，便于直接编写和调整复杂筛选表达式。
- 排序规则改为紧凑标签：支持切换字段、切换升降序、删除单条、清空全部与撤销，并可通过六点手柄拖动调整优先级。

## 改进

- 筛选展开区支持滚动，排序与应用操作保持固定；展开高度不超过数据区域的 35%，条件较多时不再遮挡操作按钮。
- “表单 / 输入”切换只在筛选编辑展开时显示，收起后保留条件、当前模式和已应用的筛选结果。
- 支持多条件、多层括号嵌套和逐行 AND / OR 切换，复杂筛选 SQL 可在输入模式与表单之间往返编辑。
- MySQL、TiDB、PostgreSQL、SQL Server、SQLite 和达梦 DM8 按各自方言处理类型转换、运算符、标识符、空字符串和 `LIKE` 通配符转义。
- 排序拖动预览跟随明暗主题，使用六点手柄和主题色反馈，不再出现突兀的黑色浮层。
- 字段详情抽屉的最低高度调整为 220px，压缩时仍完整保留字段信息、值编辑区和保存操作。
- 应用内更新显示下载百分比、已下载大小和总大小，并在弹窗中展示对应版本的更新说明。

## 修复

- 修复筛选 SQL 解析在中文等多字节字符边界处触发的 panic。
- 修复 SQL 编辑器补全、诊断增量更新、语句定位和参数替换中的同类 UTF-8 字符边界风险。
- 修复复杂嵌套条件切回表单后结构丢失、`LIKE` 条件无法恢复以及运算符显示不正确的问题。

## 验证

- 通过 `cargo fmt --all -- --check`、`cargo check --workspace --locked` 和 `cargo clippy --workspace --all-targets --locked`。
- 通过筛选方言、条件往返、多字节文本、复杂嵌套与组合条件单测，以及真实生产视图的无头交互和拖拽排序 E2E。
- 真实 PostgreSQL、SQL Server 和达梦实例的连接级验收不在本次自动门禁内，方言 SQL 通过针对各数据库类型的单测覆盖。
