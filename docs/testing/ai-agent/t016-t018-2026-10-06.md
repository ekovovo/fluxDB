## 改动要点

- `AiControl::StartTurn` 改为携带 `TurnSpec { model, messages, max_output_tokens, target_json, permission }`；
  新增 `AiRuntimeHandle::start_turn_with_spec`，保留 `start_turn(ModelRequest)` 兼容入口（目标为空、权限内核默认）。
- 新增 `spawn_ai_runtime_with_tools(provider, sink, capacity, tools: ToolCatalog, audit: Box<dyn SecurityAuditHook>)`；
  简易入口 `spawn_ai_runtime` = 空工具目录 + `DenyAllAudit`（fail closed）。
- actor 跑完整 `TurnRunner`：schema 校验 → 强制审计 → 授权（deny 优先）→ 执行 → 有界投影。
- `AiEvent` 新增 `ToolStarted` / `ToolFinished{receipt}` / `ApprovalRequired{plan_hash,scope}` / `Notice{text}` / `Paused{reason}`。
  终态映射：`Completed`→`Finished{Stop}`、`Cancelled`→`Finished{Cancelled}`、`Failed`→`Error`+`Finished{Error}`、
  **`Paused`→`Paused`（不补 `Finished`）**。
- `ai_loop`：逐事件消费 stream 并在事件之间检查取消（取消后不再继续刷流式文本）；
  新增 `LoopEvent::ToolCallRequested`；纯文本被长度截断时发 `Notice`。

## 子 Agent A 独立测试（`tests/ai_runtime_tools.rs`，6 用例全过）

全部经 `spawn_ai_runtime_with_tools` / `spawn_ai_runtime` + `start_turn_with_spec` 生产入口驱动，
逐条核对 `RecordingTool::call_count()`：

| # | 场景 | 预期 | 结果 |
|---|---|---|---|
| 1 | Read 工具（默认 policy + 审计 Allow） | `ToolCallRequested→ToolStarted→ToolFinished(Succeeded)→Finished(Stop)`，`seq` 严格递增，`call_count()==1` | 通过 |
| 2 | Write 工具 + 默认 policy | 合成 `Denied` 回执，`call_count()==0`，终态 `Finished(Stop)` | 通过 |
| 3 | Write + `write_allowed=true` + 审计 Allow | 有 `ApprovalRequired`（plan_hash 非空、scope.tool_id=`db.execute`），终态 `Paused`，无 ToolStarted/ToolFinished，`call_count()==0` | 通过 |
| 4 | 审计 Hook 返回 `Err` | Denied（fail closed），`call_count()==0`，正常收尾 | 通过 |
| 5 | 中途 `handle.cancel(turn_id)` | 终态 `Finished(Cancelled)`，无 `ToolStarted`，写工具 `call_count()==0` | 通过 |
| 6 | `spawn_ai_runtime` 空目录 + 请求 `db.query` | 不执行、`Notice` 含"未注册"、模型收到 `unknown_tool` 后正常 `Finished(Stop)` | 通过 |

平台：macOS；未验证 Windows/Linux。

## 未完成 / 已知缺口

- **桌面端未消费 `AiEvent`**：`apps/fluxdb-desktop` 的 AI 面板目前**完全不使用** runtime actor（无 `spawn_ai_runtime`/`AiEvent` 引用），
  因此工具卡、审批卡、暂停态还不会出现在真实界面里。这是 T028 的剩余工作。
- **审批行未落盘**：`fluxdb-storage::ai_platform::audits`（`insert_tool_audit` / `create_approval` / `decide_approval` /
  `find_valid_approval`）已存在，但 actor 没有 DB 句柄，尚未在工具调用前后写入/复核；当前审计与审批只存在于内存。
- **暂停后无恢复流程**：`Paused` 之后没有 `AiControl` 恢复入口（需要按 approval 复核后带着 tool 回执重跑该 Turn）。
- **插件层未接**：`authorize` 由内核直接调用，插件的 Allow/Deny 尚未接入。
- **真实模型/真实库未验证**：本轮全部为 scripted Provider + RecordingTool，无网络、无真实凭据。
- `block_on_ready` 仍不支持挂起型 Provider（需要真实异步执行器）；属既有切片约束。
