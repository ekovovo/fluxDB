# T040 原生图表/报告 UI 与安全导出

## 交付范围

- **报告读取（App）** `crates/fluxdb-app/src/parts/ai_artifact_report.rs`：`load_ai_report` 只读
  `ai_artifacts` 行 + `ai-artifacts/<uuid>.json` 快照，投影为 `AiReportView`（标题/类型/renderer/
  口径/来源/SQL/真实行）。**打开报告不重新查询数据库、不调模型、不刷新来源版本**。快照缺失、
  长度或指纹不符、非法 JSON、未就绪状态都给出 `data_issue` 可见解释，仍保留可解释元数据，
  绝不用空数据伪装正常报告。
- **来源 SQL**：从产出调用的 `arguments_redacted_json` 读回 `sql`/`original_sql`/`statements`/`command`，
  只读展示，不重新执行。
- **安全导出（App）** `render_ai_report_export` / `write_ai_report_export`：
  - Markdown 直接输出 renderer 正文；**HTML 只做转义后的静态文档**，无脚本、无远程资源、无外链样式；
    JSON 输出产物 spec + 真实来源行。
  - 写入目标来自用户系统保存对话框（路径授权）；拒绝符号链接、目录、非法文件名与缺少父目录；
    先写 `.tmp` 再改名，回读逐字核对，失败清理临时文件、不返回成功事实、不残留半截文件。
  - 单文件仍受 `BI_SNAPSHOT_MAX_BYTES`（1 MiB）上限约束。
- **报告弹框（GPUI）** `apps/fluxdb-desktop/src/main_parts/ai/report.rs`：会话产物卡 → 独立大弹框
  （`Dialog`，宽 960dp，非设置页、非询问 AI 第三种形态），内部滚动；含状态/口径标签、**真实指标条**
  （宿主对快照点求和/极值，只做算术不推断结论）、**原生图表**（`gpui-component` `BarChart`/`LineChart`，
  用真实快照点）、**表格**（真实列/行，超 50 行或来源抽样时标记）、renderer 正文（Markdown）、
  来源与可追溯信息、可折叠「来源 SQL」。关闭按钮/Esc/遮罩关闭，内部点击不穿透。
- **会话产物卡（GPUI）** `message.rs` + `report.rs`：消费持久化 `artifact_ref` 片段，渲染标题/状态/
  renderer/来源数/截断与失败码，提供「SQL / 导出 / 打开报告」三个动作，三者进入同一弹框（导出直达时
  先开弹框再走同一路径选择与安全写文件链路）。`failed` 状态明确提示 renderer 不可用或渲染失败并禁止导出。
- **可访问性**：报告是 `Dialog`（Esc/遮罩/close_button/keyboard），弹框承载键盘焦点；图表以原生绘制，
  表格与来源为真实文本控件；颜色全部走 `UiColors`（明暗主题兼容）。

## 数据到页面闭环（设计 §39.5）

自动化用例走**生产链路**：真实 SQLite 结果 → `ai_artifacts`/快照 → `load_ai_report` →
`AiReportView` → 弹框控件。断言的是弹框内真实呈现的指标/图表/表格/来源/正文与快照值一致
（`items[1].revenue == 34`），而非只查数据库或只截空态。

### 本轮实机暴露并修复的缺陷：分类轴标签相互遮挡

附件格式报告（13 个分类，`stl_dentalwings` / `obj_dentalwings` / `ply_dentalwings` 等长标签）
在分类轴最右侧出现标签重叠、不可读，违反设计 §39.4「不得有遮挡、不可读」。

原因：`gpui-component` 柱状图的分类轴文本直接取 band 值，且 band 值同时是 `ScaleBand` 的
身份 key，无法只截断显示文本而不影响身份。

修复（`apps/fluxdb-desktop/src/main_parts/ai/report.rs`）：
- 新增 `ai_report_band_labels`：按弹框真实可用宽度计算每个分类的文本预算（半角 1 单位、
  CJK/全角 2 单位），超出预算的标签截断加省略号；截断后若出现重名，追加序号消除歧义，
  保证 band 身份唯一、不会把不同分类合并。
- 柱状图改用截断后的唯一文本作为 band（轴标签），并用 `tooltip_title` 显示**完整原值**。
- 修复后 13 个标签互不重叠：短标签（`stl`、`ply`）保持原样，长标签截断到预算内。
- 回归用例：`band_labels_are_truncated_fitted_and_unique`、
  `band_labels_disambiguate_identical_prefixes`、`band_labels_keep_short_categories_untouched_even_when_narrow`。

复测：`ai_panel_tests` 串行 96/96、`ai_artifact_report` 9/9、报告弹框用例 2/2；`cargo fmt --all`、
`cargo check --locked --offline` 通过。用户真机复看 13 分类柱状图，确认遮挡已消除。

**结论：T040 于 2026-10-13 经用户真机、真实库 `community_test` 验收通过并勾选。**
