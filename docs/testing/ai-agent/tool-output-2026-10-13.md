# 通用工具输出预算与续读

## 范围

- 所有通过 `ToolCatalog::project` 发送的工具回执共用预算；不是 SQL 专用策略。
- 普通回执默认 4 KiB / 1,000 估算 token；主动分段读取默认 16 KiB / 4,000 估算 token。工具自己的字节上限更小时取更小值，预算预留发送信封开销。
- `Sample` 声明可裁剪的条目字段：小集合完整发送，大集合保留预算内完整前缀。原始执行回执不变，不再固定保留 5 行。
- `Opaque` 不猜测业务字段；超限保留执行状态、错误、部分成功标记及任务/产物/媒体引用等关键信息。未展示的告警明确标记，详细输出保存为可重组的 UTF-8 片段。
- `Read` 保持内容与原续读位置一致。整页被省略时不继续回显原游标；可读取该页的输出片段快照，避免跳过数据。
- 文件、引用、知识、编辑器、页面数据及结果分页读取明确声明 `Read`。不存在的命令/MCP/媒体工具没有新增实现；后续注册默认继承 `Opaque`，必须继续遵守原有授权和敏感信息约束。

## 生命周期与边界

- 结果使用唯一 UUID，不复用 `result-1` 等编号。
- 引用归属当前 session/turn 的执行实例；执行结束、暂停后重新装配或重启即不可读。没有新增跨轮/跨会话缓存或恢复授权。
- `content_type=items` 的游标索引条目；`output_fragments` 的游标索引片段，正文按 `offset_bytes` 重组。不得把集合行数当作 JSON 片段游标。
- 查询 `acquisition_truncated` 与展示 `delivery_truncated` 分离。快照只包含原工具实际取得的数据，不能续读未采集的数据库行。
- 分页单条超过请求字节预算时返回 `result_item_too_large`，不返回超预算的单条或无进展空页。
- 通用输出原文快照最多 2 MiB；每执行实例最多 128 个快照、合计 16 MiB 序列化条目。容量不足明确反馈，不重跑有副作用工具。
- spill 文件在 Unix 上使用 0600 和独占创建。落盘事实有 24 小时清理期限；启动恢复及后续生产任务准备时清理，任务前每批最多 128 个文件。清理拒绝路径穿越及越过受控根的目录。
- 原始回执仍是审计事实；模型引用失效和临时文件删除不等于删除会话审计历史。

## 有界历史

- 新轮只加入最近最多 12 条、合计不超过 4 KiB / 1,000 估算 token 的工具事实：工具、调用定位、状态、错误码及条目数量。没有加入历史数据行、文件正文或额外授权。
- 明确标记历史引用不可读；助手正文提到旧句柄不代表当前可用资源。
- 运行中的工具历史控制在 32 KiB / 8,000 估算 token 内，保留调用配对和最新读取页，优先收紧旧回执。必要状态也放不下时暂停，不删除配对或丢弃最新页。
- 输入预算同时计算正文、调用参数、配对标识和工具定义。首次压缩与每次模型发送前使用相同估算，未知模型窗口不臆造容量。
- token 数是近似值，真实用量仍取 Provider usage，未新增金额或累计用量上限。

## 回归场景

- 非数据库集合：超过 5 行的小结果完整交付，大结果按预算裁前缀。
- 字节符合上限但 CJK token 超限；原输出通过片段快照无损重组。
- 部分失败的执行回执保留失败状态、影响数量及告警省略标记。
- 主动读取采用独立预算；内容省略时不能跳到原下一页。
- 连续两个执行实例产生首个结果，旧引用不命中新结果；其他 session/turn 不能读取。
- 来源工具只执行一次，通过正式循环调用分页工具直到重组完成。
- 原始回执、调用配对及最新页保持不变；旧回执收紧并检查累计预算。
- 持久化历史只提供事实、不回放数据值；过期 spill 清理不越过受控根。
- SQL/BI 原有来源校验、快照哈希、产物创建与分页链路继续验证。
