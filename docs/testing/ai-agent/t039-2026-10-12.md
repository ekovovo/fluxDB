# T039 产物 schema、source 引用与内置 BI 插件

## 交付范围

- Core：版本化 `ArtifactSpec`，报告 / 折线与柱图 / 表格 / 说明块；口径引用与假设、RFC3339 时间范围、时区、过滤条件、静态刷新语义、模板版本、可访问性描述及大小上限。
- Storage：`ai_artifacts` 草稿 / staged / ready / failed / expired 状态与 revision CAS；同事务写入正规化 `ai_artifact_sources`。声明句柄、结果行、实际产出调用必须一致且属于同一任务；提交 ready 时再次校验来源仍 available、调用 succeeded。
- App：`builtin.bi` 的 `artifact.create`、`artifact.add_block`、`artifact.finalize`。全局实例或 Agent 绑定禁用时不注册，仍经过现有 schema / 审计 / 白名单 / 全局工具开关 / 内核权限链。
- 快照：受控 `ai-artifacts/<uuid>.json` 保存有界真实来源行、列结构、来源时间版本、spec、安全 Markdown、截断事实；临时文件写入与同步、改名、回读核对、提交 ready。失败不得返回假文件，提交失败清理本次文件，不改写 SQL 结果。
- 能力可替换：工具依赖 `Arc<dyn ArtifactProducer>`，可信 renderer 依赖 `ArtifactRenderer`；没有增加第三方动态代码加载或任意路径写入。

## 有依据的数据

模型只能提供来源句柄与字段名，不能提交图表数据值。来源由宿主从真实查询回执和本轮 `ResultStore` 解析；结果行和 ToolCallRef 的归属、执行状态、字段存在性、数值性均复核。图表数值列严格使用 JSON number，数字字符串不自动转换；零行表格仍按真实列结构校验，空列不凭空断言为数值列。

已确认口径引用必须属于本轮授权知识，完成时再次检查 confirmed 状态；缺少已确认定义时明确标注假设。模型说明、声明时间范围与过滤文字不是已证明的业务结论，在 Markdown 中明确标为未独立核实。没有尝试自动证明任意自然语言结论与 SQL 的语义等价。

预览与快照的截断分别表达：工具只回给模型最多 50 点并标记 `points_truncated`；快照图表最多 500 点、表格最多 200 行、单元文本最多 256 字符、单文件最多 1 MiB。来源截断、null 点省略、展示裁剪都不能伪装成全集。文件内保留生成时数据，后续查看不重新查询。

Markdown 转义模型文字、列名和数据库文本，不能由文字构造主动 HTML 或远程 Markdown 资源。HTML / PDF / XLSX 导出尚未实现。

## 验收场景

| 场景 | 实际断言 |
| --- | --- |
| 真实查询到产物 | 隔离 SQLite `sales` 已知值 web=12、store=34，经 query → create → add table → finalize，核对图表点、表格值、source 行、产物片段、文件内容 / 字节数 / 指纹 |
| 真实宿主 ID | 受控 Provider 从下一模型请求中的真实工具回执取 artifact ID，不预置成功回执，不跳过执行 |
| 无依据来源 / 字段 | 伪造句柄、未知字段、非数值字段、未授权口径引用、额外自填数据字段被拒绝，无产物残留 |
| 任务隔离 | 跨 session / turn 来源、跨任务加块 / 完成、错误的产物片段身份被拒绝，不修改原任务 |
| 插件替换 / 关闭 | 替换 producer 实际走相同工具链；全局实例或 Agent 绑定禁用均移除入口 |
| renderer 故障 | 缺失 / 失败返回受控错误、产物 failed，原 SQL 调用及结果各列保持不变 |
| 文件与提交故障 | 受控根是文件时写入失败；SQLite trigger 注入 ready 提交失败，failed 卡片和数据库状态一致，无假文件、无本次快照残留 |
| 空结果 / 截断 | 零行表格合法；51 点预览只给 50 点且标记，而文件仍保留完整图表；null 点省略标限制；宽行 spill 保持原位置分页形状 |
| 状态 / CAS / 事务 | revision 冲突、终态 Turn、非法状态推进、来源数量 / 身份不一致均拒绝；第二来源写入失败时整笔回滚 |
| 取消 | 取消后的创建 / 完成不写产物或文件；实际执行回执区分 cancelled 与 failed |
| 快照完整性 | 合法 JSON、相同行数 / 字节数的 spill 篡改也返回 `result_damaged`；跨会话 / 释放句柄不可读取 |

## 验证命令

实际平台：macOS arm64。主机已有依赖，使用 `--locked --offline`，无真实模型请求、无生产数据库或用户配置读写。

```sh
cargo fmt --all
cargo check --locked --offline
cargo test -p fluxdb-core --locked --offline
cargo test -p fluxdb-storage --locked --offline
cargo test -p fluxdb-app --test ai_bi_artifacts --test ai_conversation_tools_guard --locked --offline
cargo test --workspace --locked --offline
```

定向结果：Core 新增 10 个产物测试；Storage 14 个产物测试；App 22 个真实 SQLite + 受控 Provider 产物集成测试，`ai_conversation_tools_guard` 6/6；全量 `fluxdb-app --lib` 827 项在偶发 socket 争用用例单独重跑后全绿。

沙箱内运行会因禁止本地监听而失败 14 项既有网络 Mock，经许可在沙箱外重跑通过。全量构建的 `serde_json/preserve_order` 特性还暴露了依赖 JSON 键顺序的测试断言，已改为按实际结构 / 声明输出形状验证；`oneOf` 与 `const` 开始生效后，原本错误依赖非法参数穿过 schema 的测试改为验证执行前拒绝，并保留独立递归脱敏测试及真实 tagged 参数回归。

三项失败经 `git stash` 在改动前基线上复现，确认与 T039 无关，未在本任务内修改：

- `ai_jev_failure_policy::timeout_falls_back_without_blocking_repeatedly`：用例注释仍按 8 秒 deadline 断言 25 秒内返回，实际约 60 秒；属于 Jev 超时策略与断言口径待统一。
- `ai_chat_model_selection_disabled_model_error_preserves_selection_and_input`、`ai_ui_default_model_selector_persists_runtime_setting`：桌面 headless 既有用例。

## 边界与未验证项

- 时区本期支持 `UTC` 与有效 `±HH:MM` 固定偏移；IANA 名称明确返回不支持，未引入手写时区表。
- SQLite 空结果丢列结构的相邻根因已用驱动 describe 修复，不重新执行查询取数；本轮真实数据库验收仅 SQLite，MySQL / PostgreSQL BI 实机未验证。
- Redis 尚无本轮可解析 ResultRef 快照，不注册不可兑现的 BI 工具入口。
- 不含 T040 原生图表 / 报告弹框 / 文件导出；现有会话产物容器消费持久化引用，draft / staged 为 pending，ready 为 complete，failed 为 error。未执行真实桌面产物打开与像素验收，不宣称 UI E2E 或原生图表已交付。
- Windows / Linux 未实际编译与运行；当前检查不代替三端验证。
- 没有新增页面读取或首条消息上传范围；AI 仅在现有授权工具链中看到查询回执、产物定位 / schema / 来源摘要和有界数据点。密码、API Key 等配置凭据不进入产物或上下文。
