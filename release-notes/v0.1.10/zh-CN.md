## 新功能

- 新增达梦 DM8 数据源：连接管理、Schema 与对象浏览、SQL 查询、表结构管理与设计、数据编辑、表数据导入、逻辑备份与整 Schema 恢复，以及达梦语义补全。
- 新增表数据导入向导：支持 TXT、CSV、JSON、XML，提供字段映射、追加/截断模式、批量进度与消息日志。
- AI Agent 新增页面查询与 SQL 编辑器修改授权：可查找并打开表、填写可见筛选条件后查询一次；可按选区改写信箱中的 SQL，写入可撤销且不会自动执行。
- 新增应用内更新：从 GitHub Release 检查并校验签名清单与安装包摘要后安装。

## 改进

- 补全引擎改为独立语义补全，补齐函数签名、词法作用域、关键字槽位收敛与诊断能力。
- AI 工具目录支持动态搜索/加载，设置修改统一经确认后的配置提案完成。
- 路线图补充达梦 DM8、国际化、应用内更新与表数据导入的完成状态。

## 修复

- 修复达梦分帧响应判断、索引列去重、表设计元数据加载阻塞与对象刷新等问题。
- 修复侧边栏刷新时已加载表短暂消失、表右键菜单越界等交互问题。
- 修复撤销/迟到结果覆盖编辑器或页面状态的问题，并补充并发与取消测试。
- 修复应用内更新无法处理带换行的签名文件，导致检查更新报签名编码无效的问题。
