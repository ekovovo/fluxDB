## 新功能

- 新增 SQL Server 数据源：支持 SQL Server 认证、TLS、数据库 / Schema / 对象浏览、T-SQL 查询、表结构管理与数据编辑、表数据导入导出、登录名 / 数据库用户 / 角色成员 / 显式权限管理，以及对象级逻辑备份与恢复。
- SQL Server 接入 AI 页面上下文与受控执行：只读查询和对象描述可在受限范围内使用，写入与高风险操作需要审批。
- 新增 SQL Server 的存储过程 / 函数对象入口、T-SQL 补全和数据库级创建 / 删除等基础对象操作。

## 改进

- SQL 补全支持裸表名跨 Schema 匹配，并继续补全下一级限定；修复含中文等 UTF-8 字符时的补全定位偏移。
- 表设计器按数据库方言扩充类型与适配列选项，支持枚举 / 自定义类型按需编辑，并校验长度与精度。
- 统一 PostgreSQL / MySQL 的列类型展示与设计表解析，保留不透明类型的参数信息。
- 压缩查询摘要元数据列，改善长列注释换行；Redis 标签按连接聚合为一级工作区。
- AI 失败 SQL 修复按实际执行来源定位编辑器语句，避免 SQL 改写后定位到错误位置。

## 已知限制

- SQL Server 首版尚未实现 Windows 集成认证、Azure AD、包含数据库用户、列级权限编辑、用户自定义服务器角色、SQL Browser / 命名实例自动解析和数据库级物理备份。
- 对象级逻辑备份恢复不能替代数据库级灾难恢复。完整能力边界见 README 的“数据库支持”表。
